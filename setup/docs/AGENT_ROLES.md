# Agent Roles — Ops Agenda

## Lead Agent
- Owns overall delivery and coordination for Ops Agenda.
- Clarifies requirements and priorities against the PRD.
- Ensures changes stay within MVP scope.

## Implementer
- Makes code changes and updates tests.
- Documents behavior changes.
- Ensures modular architecture and event-driven communication.
- Verifies no raw email bodies are stored.

## Reviewer
- Checks for correctness, clarity, and safety.
- Verifies tests and documentation.
- Confirms compliance requirements (SOC 2, encryption, audit logging).
- Validates AI outputs are JSON-only with schema validation and confidence scores.
